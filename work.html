StyleVault

2026

A fashion inspiration organizer built for stylists, creative directors, archive collectors, and anyone whose camera roll is 80% outfit screenshots. Organize fits into curated collections, tag them by mood, and reorder your archive exactly how you see it.

Not a Pinterest clone — an editorial-grade personal workspace: dark, minimal, and built to feel like a fashion publication rather than a productivity app.

Role
Fullstack Developer
Stack
Vite React TailwindCSS Supabase React Router
Learned
SQL migrations, database querying, deployment, drag and drop functionality.
Next

Links
GitHub ↗ Live ↗

What it does

  • Collections

    Group inspiration into named archives — Dark Streetwear, Opium, Archive Fits, Techwear and more.

  • Masonry Grid

    A Pinterest-style layout with varying image heights for the collection detail view.

  • Drag & Drop Reordering

    Pick up any inspiration card and reorder it within a collection, with smooth lift, scale and shadow animations.

  • Mood Tagging

    Tag each piece — Streetwear, Avant-Garde, Minimalist, Archive, Luxury, Techwear, Opium, Casual — and filter a collection by mood.

  • Add Inspiration

    Upload an image, write a caption and assign a mood tag in a single modal.

  • Empty States

    Clean, on-brand messaging whenever a collection has no pieces yet.
